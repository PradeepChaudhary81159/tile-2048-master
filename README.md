# Tile 2048 Master – Website

Official mini-site for **Tile 2048 Master** (PC AppStudio).

## Pages

| File | URL path | Use |
|------|----------|-----|
| `index.html` | `/` | Home |
| `privacy.html` | `/privacy.html` | Privacy Policy (Play Console) |
| `terms.html` | `/terms.html` | Terms of Service (Play Console) |
| `styles.css` | shared theme | App-style colors |

## GitHub Pages

1. Create a repo (e.g. `tile-2048-master` or `username.github.io`).
2. Upload these files to the **root** (or `docs/` folder).
3. Settings → Pages → Deploy from branch `main` / root.
4. Site URL examples:
   - `https://YOUR_USERNAME.github.io/REPO_NAME/`
   - Privacy: `https://YOUR_USERNAME.github.io/REPO_NAME/privacy.html`
   - Terms: `https://YOUR_USERNAME.github.io/REPO_NAME/terms.html`

## Play Console links

- **Privacy Policy:** `.../privacy.html`
- **Terms of Service:** `.../terms.html`

Both must be public HTTPS pages (GitHub Pages provides this).
